# LHW21 — Learning multiple-scattering solutions for sphere-tracing of volumetric subsurface effects

- **Authors / year / venue:** L. Leonard (listed with Univ. of Havana in the preprint), K. Höhlein, R. Westermann (TUM); Computer Graphics Forum 40(2), pp. 165-178, Eurographics 2021; doi 10.1111/cgf.142623. Some sources spell the first author "Ludwic Leonard".
- **Paper:** https://arxiv.org/abs/2011.03082 (local: `artifacts/research/papers/neural/LHW21-leonard-2021.pdf`); also https://diglib.eg.org/items/ce494cc9-9662-4833-922d-baa135ab8fab/full
- **Project page:** none found
- **Official code:** https://github.com/lleonart1984/eurographics_cvae — C++ (data generation, CVAE path tracer shaders; training in Python), MIT, also archived at https://zenodo.org/records/4551145 (82.5 MB zip, MIT). Includes a comparison implementation of tabulated scattering statistics after Müller et al. 2016.
- **Third-party code:** none found
- **Data / weights:** generated by the provided scripts (training data for spheres); the Zenodo archive is code plus models as shipped, not inspected further.
- **Cited by HaloRT as:** learned statistical path model; a learned multiple-scattering shortcut inside a path tracer (contrast with HaloRT's image-space inference).

## Summary
Problem: long scattering chains make path tracing of dense translucent media slow. Method: learn, for a homogeneous sphere of unit radius with varying density, the statistics of random walks. A first conditional VAE samples the number of scattering events (hence absorption), a second samples the exit position and direction, and a third generates a representative in-sphere point and direction used for next-event estimation of direct lighting. A sphere-tracing strategy (largest sphere that fits the geometry, with absorption) then jumps the light path to the boundary in one step. The networks are tiny: at most three layers and 16 nodes, evaluated in a GPU shader.

Results and cost: quality on par with reference Monte Carlo; speedups grow with density (search summary reports roughly 1.5x at low density, up to about 3.1x at high density; not re-checked in the paper). Limitation: thin or sparse features that cannot hold large spheres, so it is a poor fit for wispy clouds. Still a path tracer, so noise remains.

## Use for us
Mostly background: shows tiny shader-evaluated networks can replace scattering simulation, but the homogeneous-sphere assumption does not fit clouds. HaloRT's stated difference is that it needs no path at all.
