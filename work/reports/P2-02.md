Design notes:
- `new Clouds(renderer, { sky?, quality?, lighting?, planetCenter? })`; renderer must be initialised. `load({volume, noise?, position})` returns the asset. `position` = base centre of the volume (x/z centre, y base), same as the flagship's `placeCloud` with [0, 500, 0]. `settings`, `timings`, `isReady`, `setQuality`, `core` (runtime), `dispose`.
- `clouds.node(colorNode, scenePass)` returns a TempNode (`updateBeforeType = FRAME`). `setup` registers colour and depth nodes as dependencies so scenePass renders first; `updateBefore` reads `scenePass.renderTarget.depthTexture`, `scenePass.camera`, resizes a three `StorageTexture` that the runtime writes (as the flagship bridge did), encodes with its own command encoder on three's device and submits it. The fragment blends `color * a + rgb`, mixed by a `ready` uniform so the plain scene shows until clouds exist.
- Sky bridge ported to `sky-bridge.ts` (own interop, optional shared layout). Created lazily on the first frame the LUTs exist, so `await sky.compileAsync()` (the sky's own recommendation) is enough.
- No-sky lighting is adapter-side (runtime has no uniform mode): a synthetic atmosphere bind group, sun radiance in a 1x1 transmittance texel, ambient top/bottom in a 1x64 sky-view column, AP off. Edit `clouds.lighting.{sunDirection,sunRadiance,ambientTop,ambientBottom}` live.
Open issues:
- `scenePass` must not be MSAA: its depth is read as a non-multisampled texture. `node()` sets `scenePass.options.samples ??= 0`; the page also uses `antialias: false`. A multisampled depth logs one warning and skips clouds.
- `setVolume(GpuCloudVolume)` throws: `runtime.setVolume` accepts only `CloudVolumeAsset`. Runtime needs a `setVolume(GpuCloudVolume | asset)` overload for `volumeGenerator` output (P2 core).
- Runtime exports `CloudQuality` 'high'|'medium'|'low' only; no 'ultra'.
- `previousViewProjection` is taken from the previous node update; with several scene passes per frame it would be wrong (unused by the runtime today).
- Uniform mode with the default sun vector looks over-bright for the parkouring cloud; defaults are placeholders for the P2 demo.
- Not done: `clouds.reflection(dirNode)` (P2-04), Clouds-owned render resize hooks beyond scenePass size.
