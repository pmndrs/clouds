Measures:
- Pack VDB parity (`--mode pack`, default `--sdf-source edt`): Parkouring dims 108x108x51 offset 167,103,13, identical to assets; R/G/B 100.0000% exact (limit: 2/255 at 99%), alpha 0, occupancy mismatch 0, SDF median |diff| 0.000 m. Stormbird 83x116x62 offset 212,198,0; R exact, G/B 99.9998% exact and max diff 1/255; SDF median 0.000 m. With `--sdf-source vdb` (resampled pack sdf grid): median |diff| 3.25 m (Parkouring), 3.45 m (Stormbird), p99 8.9 / 16.8 m: passes the 4 m limit too, but edt is the default since it is exact.
- Conversion time (wall incl. ~3 s hython start): Parkouring 4.0 s, Stormbird 4.6 s (script-internal 0.6 s). Mode 2 test cloud (4 m VDB, 1.26 M active voxels, resampled to 8 m, 114x87x70): 16 s wall, 3.2 s internal. Mode 3 (level set, 4 m): 7.8 s wall.
- VDB grid contents (both pack files): 4 float grids, all voxel size 8 m, identity-scaled transform (no rotation), voxel (0,0,0) centre at (-2044, 324, -2044), i.e. the 512x64x512 grid centred on x/z = 0 with corner at y = 320. Grids: `dimensional_profile` (fog volume, background 0, sparse: Parkouring 52,519 active, Stormbird 122,413), `detail_type` (fog, ~dense 16.7 M active), `density_scale` (fog, ~dense), `sdf` (level set, dense, background 3309 / 2631 m, values in metres, quantised on the 17 m pack grid). VDB axes are y-up: index X = map column, Y = height (0..64), Z = map row (0..512). Read order of `voxelRangeAsFloat` is X fastest, then Y, then Z. Profile values are real floats (e.g. 0.00016), TGA occupancy = 8-bit round(profile*255) > 0, which is what reproduces the TGA crop.
- Mode 2 (fog): `make_test_cloud.py` builds python SOP spheres -> vdbfromparticles (fog) -> volumewrangle (fbm noise); `--width 800 --count 16` (about 800 m wide, 470 m tall; wider 1.4 km versions come out at 11 MB, over the 4 MB budget) converted to `assets/clouds/houdini-test/` (cloud.json 2.3 KB, nvdf.bin 2.78 MB, sdf.bin 1.39 MB). Profile ranges 1..255 over 20% occupied voxels; detail 38..217; density scale 13..255.
