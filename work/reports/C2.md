# C2 Shape closing as a standard converter step for imported sims
Status: ready for review

What it does
- **Fog mode is the sim-import path** and now defaults to R1's recipe: `--close 32` (ball closing of the iso mask, metres, before SDF/profile; `0` = off), `--scale-top 1` (density scale = pack height trend rescaled to top 1, R1 `hconst:1`; `0` = old pack scale x (0.5 + 0.5 density/p99)), `--depth-shift 0` (height-only detail type; pack fit 0.25). `--no-sim-defaults` restores the pre-C2 fog output (individual options still win). Pack and sdf modes keep their old defaults; `--close` is refused outside fog. Hero (`--fine-voxel-size`) conversions close the fine mask. Recorded in `cloud.json` `converter.shaping` and the report (`closing`).
- **Fields outside the profile, all fog/sdf conversions:** `--fields-outside 2` (default; 0 = old) carries detail type and density scale 2 voxels past the profile edge with the nearest inside value (`nm.extend_fields`; ties = mean of the equally near 6-neighbours). Profile and SDF are unchanged, so occupancy is identical. Pack mode copies the pack's own grids and is untouched.
- **Bug fixed relative to R1's copy:** closing pads the array with empty voxels. R1's numpy variant ran on the cropped array, so a cloud whose bounding box sat near a face (A2 wide, margin 1) got a filled slab down to the face (slice z=0 fully occupied, 13292 voxels). `close_mask` now keeps flat bases flat.
