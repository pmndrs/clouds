Usage:
- `?impls=ours,photo&photo=<ref>` (any pane order; `photo` combines with skypro/takram). `<ref>` is `/@fs/<abs path>`, a bare absolute path (`/Users/...`, rewritten to `/@fs/...`), or an http(s)/blob URL. `?photofit=cover|contain` (default contain = letterbox).
- Without server access: drag an image file onto the page, or the bar's "photo file" button.
- Bar: `photo: contain/cover`, `photo overlay: on/off` (photo covers the whole stack over the renders), `photo opacity` slider; key `P` flips the overlay between opacity 1 and 0. Query: `?photooverlay=1&photoopacity=0.5`.
- Labels on every pane now show the sun elevation and bookmark; the photo pane's label shows file name, pixel size and fit.
- A `?photo=` that fails to load fails the harness (the error says to use drag-and-drop if fs.allow is the cause).
