Status: ready for review
Changed: `packages/runtime/src/generate/`: `passes.ts` (new: generator-only WGSL, the EDT, storm, shape, nvdf, profile and sdf passes), `generator.ts` (new name of the GPU generator, was volume-generator.ts), `volume-generator.ts` (now light: NvdfParams, NVDF_DEFAULTS, altoFractions, jfaStepSequence, PARAM_BYTES), `shaders.ts` (only BILLOW_WGSL, SPECIES_WGSL, WEATHER_WGSL), `index.ts`, `stamp.ts`, `streaming.ts`, `evolution.ts`, `presets.ts` (imports). `work/BOARD.md`: B2 -> [r].

## The finding
B1's premise (split shaders.ts) alone does nothing: with it split, the core was byte-identical. The generator WGSL was in core because `sky-layer.ts` imports `NVDF_DEFAULTS` and `altoFractions` from `generate/volume-generator.ts`, which imported all the generator passes, and esbuild's code splitting keeps whole modules in a chunk. So both halves were needed: WGSL split (passes.ts) and the GPU generator moved to `generator.ts`, leaving `volume-generator.ts` free of any WGSL. Every export path X3's files import is unchanged (`generate/shaders` BILLOW_WGSL; `generate/volume-generator` NVDF_DEFAULTS/altoFractions/NvdfParams; `generate/weather`). No file outside `generate/` was edited.
