What was built:
- **S3 table mode** (`SkyLayerSettings.profileMode` 1; 0 = species law, default). Both 64×64 tables + their per-type-pair column peaks live in the sky params uniform (static part, written once; 12.3 KB; dome/shadow/light grid see it via `SKY_PARAM_BYTES`). Per column: top type from the species row (`SPECIES_TOP_TYPES` 0.14/0.24/0.33/0.45/0.9, or `topType` uniform), **bottom type independent** (a world-anchored 6 km value-noise field `bottomTypeLo..Hi` 0..0.7, or `bottomType` uniform; the weather map has no free channel, ndfA.B is its home once G reads the NDF). Min height = species base; max height = species depth × mass^(1/p) (so small clouds are low domes, not drums); field f = s·V/peak + billow − τ (NE additive structure, billow capped to [−0.6P, 0.75P]); depth → same profile ramp / detail / scale as the species path; the table value sets softness (slow ragged ramps erode deeper).
- **0.27 floor, decided:** column min height = table floor (17/64). Below it the product is identically 0, so mapping min height to h 0 only lifts every base by 27 % (setting `tableFloor` 0 keeps the literal mapping; `s3-table-floor0`). Top type < ~0.12 has a peak product < 0.2, so species never map below 0.14.
- **Bottom table smoothing:** the slide's bottom image is a 15-colour palette; raw steps drew terraces on every flank. Smoothed in height (radius 2 rows bottom, 1 row top), floor kept; tests pin crisp-vs-ragged.
- **S4 erosion law** (`erosionLaw`, layer only; the voxel box keeps N3): 0 ValueErosion (default), 1 HZD additive `sat((1−n) − (1−P))`, 2 Nubis Evolved = 1 + NE p.105 `pow(.,0.27)` in place of N3's `pow(d, lerp(.3,.6,S⁴))` (ours: NE prints 0.27 for the envelope model), 3 additive with raw noise (sign check).
Measures (my read; the owner judges):
- S4 (corrected 2026-10-10 after orchestrator review): every S4 capture ran at the runtime default noise MIP k = 0.002 (SD1, 5c1e053; no override in the queries; an explicit `c_mipDistanceScale=0.002` run differs from the default run by 0.46/255, the run-to-run noise). My first report blamed k 0.01; that was wrong. Re-measured at k 0.002 and 0.0015 (`s4-k0015-e0..3`, rows added to `sheet-s4-erosion.jpg`): law 1 vs law 0 mean |Δ| 0.34 (horizon) / 0.41 (below) at k 0.002, 0.56 / 0.65 at k 0.0015, i.e. at or just above run-to-run noise. **Law 1 ≈ law 0 at both k, and the cause is the laws, not the MIP:** they share the zero set (silhouettes identical), and in the core 1 − n (n ≤ 0.3 billowy) goes through N3's `pow(d, 0.3..0.6)` to about 0.93 inside a body that is opaque anyway, so the texture difference cannot show. k 0.0015 vs 0.002 itself changes law 0 by 0.73-0.82/255. Law 2 is denser and smoother. Law 3 carves the bodies into chunky broken masses with pitted holes: closest to image31's broken silhouettes, but with negative space in the cores (same at both k).
- S3: bottom type works as intended (bt0 flat bases, bt1 bases higher and more broken with satellites); top type 0.25 gives the most cumulus-like domes. With the species top types (0.33-0.45 straddle the table's jump at 0.44) clouds read as **lidded, tiered pancakes** (the table's dip/shoulder at h 0.5-0.7 makes overhanging shelves, as in N3 image28); NE hides them under strong large-scale noise, our billow + up-rez does not. Against NE p.23-27 and image31 neither mode matches yet: ours is pebbly with horizontal grain; theirs has soft rounded lobes.
