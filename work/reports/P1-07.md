# P1-07 Cloud shadows on scene geometry
Status: ready for review
Changed: packages/runtime/src/{runtime.ts,shaders/composite.wgsl.ts,shaders/frame.wgsl.ts}, examples/lab/flagship/{main.ts,bookmarks.ts}. three-bridge.ts needed no change (alpha already multiplies the scene).
What
- Composite: for pixels with scene depth < 1, intersect the sun ray from the surface with the volume box, sample the light grid 1.5 voxels inside the entry (clamped to mid-chord), tau = grid.x * lightDensityScale (grid already includes densityScale, same units as march.wgsl). shadow = mix(1, 0.8 exp(-tau) + 0.2 exp(-tau/4), shadowStrength); result.a *= shadow. Sky pixels untouched.
- Composite layout gets light grid texture+sampler at bindings 7/8; two prebuilt bind groups (one per grid ping-pong slot, selected by gridStep.front), rebuilt only with the depth view. No per-frame allocation.
- New setting `shadowStrength` (default 0.85, 0 disables); uses the former Frame _pad0 (f[42]). Flagship panel slider.
- Frame order: lightGrid.encode runs first in runtime.encode every frame regardless of camera visibility, so the grid is always current (it lags the sun by up to 8 slices, as before).
- Horizon seam: caused by the flagship ground plane (2e6 wide, edge inside the 1.5e6 far plane at some azimuths). Plane enlarged to 8e6; seam gone in edge.jpg.
- Bookmark `shadow`: ground-shadow centre S = cloud centre - sunH * (centreY / tan(elevation)); camera 25 m up, 0.35 r on the sun side of S, aimed at the ground 1.9 r beyond S along the shadow axis.
Verified: pnpm check green; captures work/captures/P1-07/ and /stormbird (ground,edge,shadow,above, 2560x1440) exit 0. Shadow visible, soft-edged (grid trilinear + soft term), offset away from the sun; edge seam gone.
Timings (ms, 2560x1440, composite): parkouring ground 0.63, edge 0.68, shadow 0.54, above 0.76; stormbird 0.98-1.25. P1-06 reported 0.4-1.2 (+-0.4 noise), so delta is within noise (<=0.2 target met; the extra cost is one box test and one 3D tap per opaque pixel). Totals stay under 3.5 ms in those shots.
Open: shadow ignores cloud detail (profile sum only, like the march's grid term) so edges follow the coarse grid; the whole scene colour (including ambient) is scaled, so strength 0.85 is an art knob. Sun below horizon: no shadow.
