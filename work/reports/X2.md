# X2 Faithful Sky Pro reference pane
Status: ready for review
Changed: `examples/lab/compare/vendor/skypro/skypro-pane.js` (grading + auto exposure), `examples/lab/compare/main.ts` (one constant: `SKYPRO_EXPOSURE` 1.35 -> 0.55), `vendor/skypro/NOTICE.md` (differences list).
Verified:
- `pnpm check` -> exit 0.
- Real demo run headless (`npm run dev`, port 5189, read-only; stopped afterwards). Demo: `?fly&noAudio`, `window.__app` is exposed, so the script set `settings.timeOfDay` (sun path lat 24, declination 6), the camera pose (6 m, looking out to sea, pitch 0.22 rad, fov 62) and hid the UI.
- captures: `work/captures/X2/real/` (Tidewater at sun 60, 10, 3 deg), `pane/` (compare pane, same view, `fov=62&lookaz=180&pitch=12.6&sunel=..&sunaz=..`), `sidebyside-el{60,10,3}.jpg` (sky above the horizon, real on top, pane below).
Findings:
- Cloud geometry was already identical. Altitude 4000 m, thickness 5200 m, density 0.019, coverage 0.49, weather/base scales, wind 12 m/s, quality "high" are the same values as Tidewater's `PRESET` (same `SkyProClouds.js`). The cloud shapes in the side-by-sides coincide cloud for cloud. The "sparse, high, small" look was the integration: exposure x1.35 with no grading (washed, pale sky), the default bookmark views (2 m, fov 50, sun 40 north-facing) and the Lambertian ground.
- Tidewater's frame is exposure 0.55 x auto exposure (refLum 0.25, clamp 0.6..6, measured 0.86 / 1.19 / 2.02 at sun 60 / 10 / 3 looking out to sea), then saturation 1.06, contrast 1.04, warmth 0.02, vignette 0.28 (+ bloom 0.05, grain, sharpen), then ACES. The pane had only ACES at 1.35.
Fix: the pane's final pass applies the same grading and vignette; `SKYPRO_EXPOSURE` is now 0.55 (Tidewater's setting) and the pane multiplies an auto exposure interpolated from the measured values over sun elevation (`?skypro_ae=<n>` overrides; default 1 elsewhere is not used). Note the compare page's exposure slider default 1 now means "Tidewater's setting", so Sky Pro is darker relative to the other panes than in P8-A (their calibration was against our sky).
Measures (sRGB pixels, real vs pane, upper sky / mid / horizon band): sun 60: (58,104,164) vs (50,96,155), (145,174,190) vs (149,176,193); sun 10: (48,81,126) vs (40,69,111), (153,166,157) vs (141,154,144); sun 3: (62,78,104) vs (51,63,89), (169,148,103) vs (153,132,87). Pane is about 8-12 % darker in the upper sky, horizon within 5-10 %.
Remaining differences: no bloom (real has a faint glow around bright clouds and the sun), no marine haze / AirHaze post (real zenith slightly lighter and hazier at low sun), no sea/island (ours is a flat Lambertian ground; auto exposure is a table, not metered), no sun disc / lens flare, TAA vs the pane's temporal resolve. The auto exposure table is only valid looking out to sea; a different view in the real demo meters differently.
Open issues: `main.ts` constant touched (X1 edits the "ours" options in the same file, rebase if needed). Run captures with `fov=62` for a like-for-like framing.
