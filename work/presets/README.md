# Hand-tuned presets

Presets exported from the Decima parity page's tuning panel (press T on `/decima/`, then "export"). Each file holds the shot (bookmark), the look, the scene values (sun, exposure, sky, tints) and only the settings changed by hand. Load one back with "import". Next session, read these as the owner's targets: they are hand-tuned dials, not judged results.
