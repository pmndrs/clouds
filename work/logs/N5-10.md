## fp16 verdict

**Not visibly different from fp32.** At 1:1 in the sheet the fp16 image and the wasm image cannot be told apart;
the ×100 difference shows faint coloured noise inside the cloud only (max 6e-3 on values ~0.4–1, i.e. ≤ ~1 % at
the worst pixel, rel L2 7.5e-4). The per-layer growth seen in N5.7/N5.8 does not compound into anything visible
in the final image on this frame. The raw env passes do exceed ENGINE.md §7's 5e-3 per-layer rel L2 (3 %), but
in the masked-out region.

## What was built

- `graph.ts` (additive): `AttnOp` (`kind: 'attention'`, prefix, bs, level, channels, src, dst, residual),
  `Op = ConvOp | AttnOp`, `isAttn`; `Graph.ops` is now `Op[]`; liveness treats an attention op's `src` as a read.
  `haloNetGraph(gather)` follows `unet` line by line and returns `{ graph, output, taps }` (taps = dump name →
  tensor id, for bisecting). `HALO_DIMS`, `HALO_IN_OUT`, `HALO_ATTN`.
- `runtime.ts` (additive): attention ops get an `AttentionLayer` (N5.9, both weight sets, channel count checked
  against the op), bound per geometry with `residual: true` into the same compute pass, in graph order;
  `engine.dispatches`. Conv path unchanged.
- Page `examples/lab/neural-engine-full/` (`?size=256|512`, `?precision=fp32|fp16|both` default both,
  `?bisect=1` compares every tap with `dumps/S-all`, `?timing=0`). Report `window.__clouds.report()`, sheet
  `window.__clouds.sheetJpeg()`. Run:

      CLOUDS_NO_WATCH=1 node_modules/.bin/vite --host 127.0.0.1 --port <free> --strictPort
      echo '[{"name":"sheet","expr":"window.__clouds.sheetJpeg()"}]' > evals.json
      node scripts/gpu/capture.mjs --url "http://127.0.0.1:<port>/neural-engine-full/?size=512" --size 2000x900 \
        --settle 2 --timeout 180 --eval-timeout 120 --out work/captures/N5-10/512 --evals evals.json

  The device is requested with the adapter's `maxStorageBufferBindingSize` / `maxBufferSize` (a 16-channel
  level-0 slot at 512² batch 6 fp32 is 100 MB).

## Rough / left

- Blend is on the CPU only; no GPU blend op yet (needed before the bench uses the engine).
- Slots: liveness sharing on, but every slot is sized for the largest tensor ever placed in it; no per-level
  pools. Attention qkv scratch is per binding, not shared. Memory not measured.
- `?bisect=1` is written but unexercised (no failure to bisect); its dumps exist at 256 only.
- Each attention op is still 2 dispatches with global-memory qkv; Down and final_conv are not fused (ENGINE.md
  later optimisations). Timing above is one number, not a table.
- fp16 stores activations and conv weights in f16; attention weights and qkv stay f32.
