## Kernel and runtime changes (all additive; `conv.ts`, `graph.ts`, `runtime.ts`)

- **`directShader`** (kernels `1x1`, `2x2s2`, chosen by `convShader` from `op.kernel`): no tile; one thread
  = 1 output pixel × oc4 groups, workgroup 8×8, `wg.z = b·ocg + og` (like kernel D). 2×2 s2 reads input
  `(2y + ty, 2x + tx)` of a (2H, 2W) source for tap `ty·2 + tx`. The einops unshuffle channel
  `c·4 + p1·2 + p2` is exactly tap (p1, p2) of channel c, so `packWeights(w, cout, c, 0, 4)` on the unchanged
  1×1 weight is the 2×2 layout. Concat (src2) supported, f32 math.
- **`src1.up`** on 3×3: loader reads `((b·C4 + k)·p.sH + gy>>1)·p.sW + gx>>1`; `p.sH/sW = H/2` were already in
  the uniform.
- **Skip `conv1x1`**: `skip1x1()` WGSL function in the `skipAt` place (after norm+SiLU, before ×2):
  bias + Σ over the one or two source chunks of `mat4x4 · vec4`, f32. Sources at bindings 8 and 9. Its weights
  and bias are appended to the op's own weight / bias buffers after both sets (offset `2·wStride +
  set·cout4·nch`, `2·bStride + set·cout4`), which keeps a concat block2 at 7 storage buffers (default limit 8;
  separate buffers made 9 and failed `createComputePipeline`).
- **External tensors**: `assignSlots` gives tensors written by no op their own slots first (no change for
  existing graphs); `binding.writeTensor(id, f32 [B][C][H][W])` packs and uploads; slot buffers gained
  `COPY_DST`.
- Runtime shape check: 2×2 s2 expects cin = 4·(c1 + c2).
- `scripts/neural/halonet_ref.py`: taps `downs.N.block1`, `downs.N.post_attn_add` for every stage and
  `ups.N.block1` (default dump unchanged; `--check` still 1.55e-6). Dumps for this page are in
  `artifacts/research/neural/fixture/dumps/256-all/` (`--dump-all`, 107 tensors), separate from `dumps/256/`
  so the attention agent's files were not touched.
