## Design as built (`experiments/neural/engine/attention.ts`)

Two dispatches per layer, both 1-D, 64 threads, one thread per (batch item, pixel), `ceil(B·H·W / 64)` groups:

1. **qkv** — per pixel of the unpadded image: RMSNorm (`x / max(‖x‖, 1e-12) · g · √C`), then `to_qkv` (C → 48,
   no bias) → scratch buffer `qkv`, f32 NC4HW4 with batch, 12 vec4 per pixel (q heads 0-3 = vec4 0-3, k = 4-7,
   v = 8-11). Reflect padding is not materialised: a 1×1 conv commutes with the pad, so step 2 reads reflected
   indices.
2. **attn** — per output pixel: block origin `(y/bs)·bs`, window rows/cols origin−2 … origin+bs+1 reflected
   (`-i`, `2n−2−i`). Per head, online softmax in f32 (running max, sum) over the 8 memory keys/values
   (`mem_kv[0|1][h]`, read from the weight buffer) then the (bs+4)² window tokens; q scaled by 0.5. Epilogue:
   `to_out` (16 → C) + bias, **optional residual** (+ un-normalised x, uniform flag `residual`), store NC4HW4.

Only queries of the centre block are computed (one per output pixel), which equals the reference's crop.

**Buffers.** Weights: one f32 storage buffer per layer, set 0 then set 1 at `setStride` floats; per set
`g[C], wqkvT[C][48], woutT[16][C], bout[C], mem_kv[2][4][8][4]` (`packAttention`). Uniform (8 × u32):
`B, H, W, C4, bs, setSplit, setStride, residual`. Bindings: 0 uniform, 1 weights, 2 src (`array<vec4<T>>`),
3 qkv (f32 scratch, `B·H·W·192` bytes, owned by the binding), 4 dst. src/dst are T = f32 or f16 (`f16: true`).
Item b uses set `b < setSplit ? 0 : 1`, as the engine.

**Residual:** fused, behind `bind(..., { residual: true })`. In the UNet every attention is followed by
`x = attn(x) + x`, so the graph should use `residual: true` and the layer's output is the stage tensor directly.

## How an engine graph calls it

    const layer = await AttentionLayer.create(device, 'downs.3.2', 8, [Wdir, Wenv], { f16, batch: 6, setSplit: 3 });
    const b = layer.bind(H, W, srcSlotBuffer, dstSlotBuffer, { residual: true });   // per geometry
    b.encode(pass);   // inside the runtime's single compute pass, between the conv ops

Prefixes and block sizes: `downs.3.2` / `downs.5.2` / `ups.1.2` / `ups.3.2` with bs 8, `mid_attn` with bs 4.
src and dst must be different buffers (dst ≠ src slot; with `residual: true` src is read in the epilogue).
The runtime would need an op kind `attention` in `graph.ts` and a branch in `runtime.ts` that calls `encode`;
not added here (another agent owns those files).

## Not covered

- Not wired into `graph.ts` / `runtime.ts` (no `attention` op kind; no slot sharing for the qkv scratch).
- Items within a set get the same input (only pass 0 is dumped), so a mix-up between items 0/1/2 would not show;
  per-set selection and per-item offsets are exercised (items 3-5 differ from 0-2 and all match).
- Fusing the following Down into the epilogue (ENGINE.md §4.4) and the workgroup-memory one-dispatch design
  (§4.1-3) are not done; no timing (rule 5).
- fp16 only stores activations in f16; weights and qkv stay f32.
