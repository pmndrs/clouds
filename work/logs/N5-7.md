## Kernel variants and how an op selects them

One generator (`convShader` in `experiments/neural/engine/conv.ts`). The op's fields choose the code:

| op field | value | generated code |
|---|---|---|
| `act` | `'none'` | kernel D (N5.6): output-channel group in `wg.z = b * ocg + og`, workgroup 8×8×1 |
| `act` | `'normSilu'` | kernels A/B: channel group in `local_invocation_id.z`, workgroup 8×8×G, `G = cout4 / oc4`, `wg.z = b`. The input tile is staged once for all output channels (loader stride = 64·G threads). Epilogue: each thread writes its 4 pixels' partial sum of squares (f32) to `ss[G][256]` in workgroup memory, barrier, sum of the G partials, `r · (g·√C) / max(‖y‖, 1e-12)`, then `r / (1 + exp(−r))`. All f32, stored as T |
| `skip` | `{ kind: 'identity', src }` | `r += x` read at the output pixel from binding 8 (packed, same channels). Generated as one `skipAt` expression, so the conv1x1 skip (N5.8) goes in the same place |
| `scale` | `2` | `r *= 2.0` after the skip |

Order in the epilogue: bias (in the accumulator) → norm → SiLU → skip → ×2 → store.

`oc4` for A/B: the tiling's oc4 (2), doubled until 64·G ≤ 256 invocations. So 16 channels: oc4 2, G 2 (128
threads); 32: oc4 2, G 4 (256); 64: oc4 4, G 4 (256). Only 16 was run. The gain `g · √C` is folded at pack time
(`packGain`), binding 7, f32, laid out like the bias (set 1 at `bStride`).

Runtime (`runtime.ts`, additive): a gain buffer per norm op (both sets), binding 8 bound to the skip source's
slot, and dispatch z = `B · ocg / localZ` (`localZ` from the generator; 1 for kernel D).

Graph (`graph.ts`, additive): `resnetBlockOps(prefix, name, level, C, x, mid, out, scale)` returns the two ops of
an identity-skip ResnetBlock (weights `${prefix}.block1.proj.*`, gain `${prefix}.block1.norm.g`);
`stage0Graph()` is init_conv plus `downs.0.0` and `downs.0.1` with ×2 on the last op.

Page: `/neural-engine/` now builds `stage0Graph`, keeps tensors 0, 2, 4, and adds four NumPy rows (items 0 and 3,
two tensors). Run exactly as in `work/logs/N5-6.md`.
