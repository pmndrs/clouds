## Layout as built (exact)

**Activations (every intermediate tensor):** NC4HW4 with a batch dimension. One storage buffer per slot,
`array<vec4<T>>` (T = f32, or f16 with `f16: true`), element index `((b * C4 + c4) * H + y) * W + x`, where
`C4 = ceil(C / 4)`, `H = W = size >> level`, b = batch item 0..5. Channel c sits in vec4 `c >> 2`, lane `c & 3`;
lanes past C are written as 0 (bias and weights padded with 0). Slot bytes = `B * C4 * H * W * 4 * sizeof(T)`.
Slots are shared by liveness (`assignSlots`); tensors listed in `opts.keep` are never freed, so they can be read
back. `readTensor(id)` returns f32 `[B][C][H][W]` (NCHW per item).

**Network input:** the planar f32 feature frame `[1, 17, S, S]` (exactly the fixture's `cond_S.f32` / the
feature pass's `packed` buffer), batch 1, shared by all items. It is never copied: the first conv's tile loader
gathers from it through a per-item table.

**Gather table** (`init_conv` only): storage buffer `array<vec4u>`, entry `b * ceil(c1/4) + chunk`, lane j =
the plane index of input channel `chunk*4 + j` for item b (lanes past c1 are 0 and masked to 0.0 in the shader).
Batch-6 rows (`HALO_GATHER_B6`, from `_modeling.py` INDICES):

| item | set | planes |
|---|---|---|
| 0, 1, 2 | dir | 0,1,2,3,4,5,6, then 10 / 11 / 12 |
| 3, 4, 5 | env | 0,1,2,3,4,5, then 7 / 8 / 9, then 10 / 11 / 12 |

**Weight sets:** item b uses set `b < setSplit ? 0 : 1` (default `batch 6, setSplit 3`: 0 = `halo_dir.tza`,
1 = `halo_env.tza`). Batch 4 with setSplit 1 and rows `[dir0, env0, env1, env2]` would be the grey-albedo variant
(not run). Per layer, one weight buffer holds set 0 then set 1: `array<mat4x4<T>>`, set 1 starts at `wStride`
mat4x4s. Within a set, mat4x4 index `(oc4 * nch + chunk) * taps + tap` (tap = ky*3 + kx), column j = input channel
`chunk*4 + j`, row i = output channel `oc4*4 + i` (Denoiser's `packWeights`, now with a `taps` parameter). One
bias buffer `array<vec4f>` (always f32), set 1 at `bStride` vec4s. Both strides and setSplit are in the uniform.

**Uniform `P`** (8 × u32): `H, W, sH, sW, ocg, setSplit, wStride, bStride`.

**Bindings:** 0 uniform P, 1 weights, 2 bias, 3 src1 (planar `array<f32>` if it is the input, else packed),
4 src2 (optional, packed, concatenated after src1's chunks), 5 dst (packed), 6 gather table (input source only).

**Dispatch:** Denoiser's mapping, unchanged: workgroup 8×8 threads, each thread 2×2 px × 2 vec4 output groups
(16×16 px per workgroup), interleaved columns (`x = ox + px*8`). Groups `[S/16, S/16, B * ocg]`,
`ocg = C4 / oc4` (2 for 16 channels), `wg.z = b * ocg + og`. Per input chunk the workgroup stages an 18×18 tile
(zero padding in the loader), loop over ky at runtime, f16 partial sums per chunk when fp16. All ops of a
graph go into one compute pass and one `queue.submit`.

Departure from ENGINE.md: none for kernel D. The channel group stays in `wg.z` here because kernel D has no
norm; kernels A/B (RMSNorm) must move it to local z as ENGINE.md §2 says.
